# 리딤코드 입력기

게임 쿠폰(리딤코드) 입력 사이트에서 여러 개의 쿠폰코드를 사람이 입력하는 속도로 순차 자동 입력해주는 도우미 도구입니다. 두 가지 방식으로 제공됩니다.

- **데스크톱 프로그램** (`app.py`) — Python + Selenium으로 실제 크롬을 원격 제어하는 독립 실행 GUI. 크롬 확장 프로그램 설치가 번거롭거나, 더블클릭으로 실행되는 프로그램을 원할 때 사용.
- **크롬 확장 프로그램** (`manifest.json` 등) — 별도 설치 없이 크롬에 "압축해제된 확장 프로그램"으로 로드해 사용.

두 버전 모두 동일한 자동 인식·안전장치 로직을 사용합니다.

---

## 1. 데스크톱 프로그램 (추천)

### 준비물

- Python 3.10 이상 (winget으로 설치: `winget install --id Python.Python.3.12`)
- Google Chrome 브라우저

### 설치

```bash
pip install -r requirements.txt
```

(Selenium 4.6+ 는 크롬 버전에 맞는 드라이버를 자동으로 내려받으므로 별도로 chromedriver를 설치할 필요가 없습니다.)

### 실행

```bash
python app.py
```

### 사용 방법

1. 프로그램 창에서 **쿠폰 입력 사이트 주소**를 입력하고 "시작"을 누르면 자동으로 크롬이 열리고 해당 주소로 이동합니다.
   - 또는 **브라우저 열기** 버튼으로 빈 크롬 창을 먼저 띄운 뒤, 그 창에서 직접 원하는 사이트로 이동해도 됩니다 (이 경우 주소 칸은 비워두고 "시작"만 누르면 됨).
2. **회원번호 / 계정정보**, **쿠폰번호**(한 줄에 하나씩)를 입력합니다.
3. **최소/최대 딜레이**를 확인 후 (기본 4~8초, 최소 3초 강제) **시작**을 누릅니다.
4. 프로그램이 자동으로 입력칸을 인식해 순서대로 채우고 제출하며, 진행 로그에 사이트가 보여준 메시지를 그대로 표시합니다.
5. 언제든 **중지** 버튼으로 중단할 수 있습니다.

### 파일 구성 (데스크톱 프로그램)

- `app.py` — Tkinter GUI (입력 폼, 진행 로그, 시작/중지)
- `automation.py` — Selenium 기반 자동 입력 로직 (입력칸/버튼 인식, 모달 처리, 결과 캡처, 안전장치)
- `requirements.txt` — 의존 패키지 목록 (`selenium`)

## 2. 크롬 확장 프로그램

### 설치 방법 (압축해제된 확장 프로그램으로 로드)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 우측 상단 **개발자 모드** 토글을 켠다
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`D:\리딤코드 입력기`)를 선택

설치 후 툴바에 확장 프로그램 아이콘이 생깁니다. (퍼즐 아이콘 메뉴에서 고정 가능)

## 사용 방법

1. 리딤코드를 입력할 게임의 쿠폰 사이트를 크롬 탭에서 연다 (또는 팝업의 "사이트 주소" 칸에 주소를 입력하면 자동으로 이동)
2. 확장 프로그램 아이콘 클릭 → 팝업에서:
   - **쿠폰 입력 사이트 주소**: 비워두면 현재 탭 그대로 사용
   - **회원번호 / 계정정보**: 해당 사이트의 회원번호(또는 UID 등) 입력
   - **쿠폰번호**: 한 줄에 하나씩, 여러 개 붙여넣기 가능
   - **최소/최대 딜레이(초)**: 코드 사이 대기 시간 (기본 4~8초, 최소 3초 강제)
3. **시작** 클릭 → 화면의 입력칸을 자동 인식해 순서대로 입력 + 제출
4. 진행 로그에서 각 쿠폰의 처리 결과 확인 (사이트가 보여준 메시지를 그대로 표시)
5. 언제든 **중지** 버튼으로 중단 가능 (현재 처리 중인 항목만 마무리하고 멈춤)

## 안전장치 (매크로/차단 방지)

- 코드 사이 딜레이 **최소 3초** 강제, 기본값은 4~8초 랜덤
- **10개 처리마다 자동으로 15~30초 추가 휴식**
- 사이트 응답 메시지에서 "비정상적인 접근", "이용 제한", "차단되었습니다", "captcha" 등 실제 차단·보안 관련 문구가 감지되면 **즉시 자동 중단** ("코드가 유효하지 않습니다" 같은 일반 오류는 차단으로 취급하지 않고 결과만 기록)
- 결과 메시지를 **연속 3회 인식하지 못하면** 안전을 위해 자동 중단 (페이지 구조가 예상과 다를 가능성)
- 한 번에 50개 초과 입력 시 경고 후 계속 여부를 다시 확인
- (데스크톱 프로그램) 매 코드마다 실제 브라우저에서 사람과 동일하게 클릭·타이핑하며, 헤드리스나 병렬 요청은 사용하지 않음
- 성공/실패 결과 화면을 닫은 뒤에는 입력 폼(회원번호·쿠폰·제출 버튼)이 다시 안정적으로 나타난 것을 확인하고 나서 다음 코드로 넘어감 (성공 시 "돌아가기"로 화면이 새로 로드되는 경우, 그 전환이 끝나기 전에 다음 코드를 제출해 회원번호가 반려되는 문제를 방지)

## 동작 원리 / 한계

- 이 도구는 **화면에 실제로 보이는 입력창과 버튼을 찾아 값을 채우고 클릭**하는 것 이상의 일을 하지 않습니다. 캡차 우회, 자동화 탐지 우회, 서버 API 직접 호출 같은 기능은 없습니다.
- 입력칸/버튼은 `회원번호`, `쿠폰`, `사용하기` 등 흔히 쓰이는 문구를 기준으로 자동 인식합니다. 사이트 구조가 특이하면(예: 입력칸이 3개 이상, iframe 내부 등) 인식에 실패할 수 있으며, 이 경우 안전하게 즉시 중단됩니다.
- 결과 판별도 화면에 새로 나타나는 확인/닫기 버튼과 그 주변 텍스트를 기준으로 하는 휴리스틱이라, 사이트마다 100% 정확하지 않을 수 있습니다. **"확인불가"로 표시된 항목은 직접 화면에서 확인하세요.**

### 파일 구성 (크롬 확장 프로그램)

- `manifest.json` — 확장 프로그램 설정 (Manifest V3)
- `popup.html` / `popup.js` — 입력 폼 UI, 진행 상황 표시
- `content.js` — 실제 페이지에 주입되어 입력칸 인식 · 자동 입력 · 결과 캡처를 수행하는 스크립트
